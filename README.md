# 合意形成の風洞実験 — 説明会を、開く前に開く。

用途地域の変更にあたって、**誰に説明義務が生じるかを、説明会を開く前に確定する**ためのブラウザ上の道具です。
PLATEAU CityHack Challenge 2026（対象自治体：**さいたま市**）の成果物。

**地図の上で用途地域の境界線を掴んで動かすと、**
その操作で高さの上限を超える棟（既存不適格）が切り出され、
**さいたま市の中高層建築物紛争防止条例の条文どおりに「説明の相手」が確定します。**

---

## 動かし方

静的ファイルだけで動きます。サーバーに置くか、ローカルで配信してください。

```bash
python3 -m http.server 8765
# → http://localhost:8765/index.html
```

**⚠ PC の Chrome ＋ マウス操作を前提にしています。**スマートフォン・タブレットには対応していません
（境界線のドラッグがマウス前提のため）。横1,280px以上を想定しています。

| ファイル | 中身 |
|---|---|
| `index.html` | 本体。地図・条例の判定・説明充足率 |
| `consent.html` | 同意率（旧称・納得率。2026-09-04 に KGI を同意率に据え替え）シミュレータ（index の右帯いちばん下の「◱ 同意率シミュレータをひらく」から、地図の上に重ねて開きます） |
| `consent_model.js` | 同意率の推定モデル（node でも動きます） |

## ★この道具が出す数字の性質（先に読んでください）

**2種類が混ざっています。画面でも色を分けています。**

| | 何か | 係数 |
|---|---|---|
| **説明充足率** | **実測。**条例の条文から機械的に決まります | **ゼロ**（推定を1つも含みません） |
| **同意率・合意率** | **推定。**査読論文と市の一次統計に基づくモデルです | **仮の値を含みます**（感度の幅を併記しています） |

**これは予測装置ではありません。**説明会の設計を考えるための思考実験の道具です。
**この数値を理由に説明会を省略する、といった使い方はしないでください。**
属性別のふるまいは**統計的な傾向であって、個人の予測ではありません。**

### 加工した旨の表示（PDL1.0 1.1-2／政府標準利用規約に基づく）

- 「都市計画決定情報_高度地区」（埼玉県オープンデータポータルサイト
  https://opendata.pref.saitama.lg.jp/datasets/2709 ）を**加工して作成**
  — さいたま市域の74区画を抽出し、対象範囲に交差する13区画に絞り、絶対高さ（15m／20m）を属性として保持しています。
- 「3D都市モデル（Project PLATEAU）さいたま市 2025年度版」（国土交通省）を**加工して作成**
  — 対象範囲の建築物25,467棟を抽出し、高さの補完・用途地域との空間結合・複合体の名寄せを行っています。
- 「令和2年国勢調査 小地域（町丁・字等別）境界データ」（総務省統計局 e-Stat）を**加工して作成**
  — 面積が最大の外環の重心を1点に落とし、丁目名の表示位置としています。

**★これらは編集・加工したものであり、埼玉県・国土交通省・総務省が作成・公表したものではありません。**

## この道具に無いもの

築年（`yearOfConstruction` は0件）／敷地界（`uro:siteArea` は0件・建物外周から推定しています）／
道路幅員（`uro:width` は0件）／路線価・固定資産税評価額（PLATEAUに含まれません）／
テレビ電波の受信障害（条例第8号エの要件。未実装のため周辺住民の棟数は過小に出ます）。
